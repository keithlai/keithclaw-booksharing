# 象與騎象人 — The Happiness Hypothesis

**作者:** Jonathan Haidt  
**難度:** ⭐⭐ 中階  
**類別:** 人性/心理  

---

## 📖 核心觀點

用一個經典隱喻解釋人類心理：

- **🐘 大象** = 情緒、直覺、本能（自動反應）
- **🧘‍♂️ 騎象人** = 理性、分析、意識（有意識控制）

騎象人以為自己控制晒，但其實大象先係真正話事嘅。**想改變行為？要先說服大象。**

## 🔑 三大重點

1. **情緒先於理性** — 我哋嘅道德判斷往往係先有感應，後有理據
2. **幸福公式**— H = S + C + V（設定值 + 環境 + 自願行動）
3. **逆境嘅力量** — 適量嘅困難反而令人成長

## 🎯 適合咩人睇？

- 對正向心理學有興趣嘅人
- 想了解點解自己會感幸福/不幸福嘅人
- 對自我成長有追求嘅人
